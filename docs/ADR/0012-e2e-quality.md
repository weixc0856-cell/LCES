# ADR 0012: 以真实课程样本和固定回归集验收

对应 SAD-001 §12 ADR-010。状态：Accepted。

## 背景

测试通过、命令退出码为 0、单次工作流跑通，都不能证明课程可讲授。
PRD §12 与 TDD-001 §13 要求用真实课程、目标分辨率、实际录制、专家评审与
学习者验证来验收；并且固定分母、抽样方法与阈值。

## 备选方案

1. 以单元/集成测试数量作为质量结论：PRD §14.4 明确禁止。
2. 只做一次演示课程：无法证明稳定性（TDD-001 §1.2）。
3. 固定基准课程 + 版本化回归集 + 人工验收（当前）。

## 决定

- 基准课程：`attention-is-all-you-need` 是端到端基准，但不是唯一材料；
  还需要概念解释型、架构流程型、代码演示型、来源冲突型样本（TDD-001 §5.2）。
- 每个基准输入、课程契约、证据台账与审计报告都记录版本与哈希；
  基准更新必须记录理由与是否重建视觉基线（§5.3）。
- 自动指标（PRD §12 表）只证明检查完成；教学质量由 Gate A/B/C 的人工记录回答。
- 每次模型、Prompt、渲染器升级都用同一回归集比较质量、耗时、成本与人工修订时间。
- 已知缺陷 REG-001…REG-010 必须逐条有守卫测试或明确的人工项
  （见 `docs/QUALITY.md` §7.1）。

## 后果

- 正面：产品结论绑定到确切课程版本；能区分"检查通过"与"课程合格"。
- 负面：完整端到端验收成本高，且需要人工时间；当前 `attention` 课程仍为 NO-GO。
- 监测点：只有一门基准课程时，不得声称"系统能稳定产出同等质量课程"（PRD §17.10）。

## 证据

`docs/design/course-product-qualification-2026-10-24.md`（Gate A/B/C 分离）、
`docs/design/p7/p7-execution-2026-10-24.md`（NO-GO 结论）、
`tests/test_motion_canvas_materials.py`（7 份固定材料与哈希清单）、
`tests/fixtures/course_plan/attention/`（冻结蓝图）。

## 回滚

不适用。放宽基准集必须记录理由并重新建立可比性；不得为让测试变绿而修改预期。
