# 产品定义（唯一产品目标）

**性质：** 本文件定义 LCES 做什么、为谁做、交付什么、不做什么。产品方向变化时只改本文件，
不另建并行 PRD 或阶段方案。实现细节见 [`ARCHITECTURE.md`](ARCHITECTURE.md)，质量标准见
[`QUALITY.md`](QUALITY.md)。

---

## 1. 定位

LCES 是一个**本地优先、模型无关、证据驱动**的课程素材生产工程系统。

输入：论文、技术文档、书籍章节，或一个明确的知识主题。
输出：可以直接在浏览器里录制、可以反复修改和重建的课程素材包。

它不替用户发布课程，也不替用户判断科学结论一定正确。它负责把资料可靠地变成
**结构化、可追溯、可播放、可录屏**的教学材料，并把不能确定的地方明确标出来。

## 2. 用户工作流

```
资料 → Research → Evidence Map → Course Outline → Script → Storyboard
     → Visual Generation → Render → Automated QA → Repair → Package
     → 浏览器逐场景录屏 + 口播 → 用户自行剪辑成视频
```

用户拿到课程包之后：

1. 打开 `index.html`，逐场景播放或按步骤讲解；
2. 按场景录屏，口播使用对应的讲稿；
3. 单独重录某个场景（场景有稳定 hash 深链）；
4. 修改内容或动画后重新构建；
5. 用质量报告判断哪些部分还需要处理。

## 3. 交付物

| # | 交付物 | 实际文件 | 要求 |
|---|---|---|---|
| A | HTML 主课件 | `build/slides/index.html` | 16:9，键盘/按钮导航，稳定 hash，离线可开，无外部 CDN；逐场景播放/暂停/重播/重置；`?record=1` 无界面 chrome 的录屏模式 |
| B | 逐场景口播稿 | `internal/speaker_script.json`、`.md` | 与场景一一对应；讲稿永不进入公开 HTML |
| C | 阅读版 | `build/reading_edition.html` | 与课件同源，可独立阅读 |
| D | 研究与证据 | `internal/source_registry.json`、`evidence_ledger.csv`、`claims.json`、`source_map.json` | 每个关键主张可回到来源与定位 |
| E | 教学结构 | `content/outline.json`、`internal/plan/` | 大纲、章节、单元、覆盖矩阵 |
| F | 质量报告 | `internal/qa/qa_report.json`、`course_content_audit.json`、`course_quality_audit.json`、`internal/qa/screenshots/` | 结构化、可复跑、绑定内容版本 |
| G | 可选发布包 | `release/v1/` + `build/artifacts/*.zip` | 只由 `release.py` 组装，白名单 |

`content/` 是公开内容模型，`internal/` 是内部证据与讲稿，`build/` 可重建，`release/` 只存放
经发布检查的资产。这个边界是类型边界，不是命名约定。

## 4. 正常生产与可选发布

- **正常生产**（研究、生成、构建、质量检查、打包给用户录屏）**不依赖**真人学员、
  人工签核或逐项审批。自动检查 + 模型审查 + 本地测试构成日常质量流程。
- **发布**（`release/`、对外版本号）是一个独立的可选动作。它要求内容版本绑定、
  证据复核与发布记录；这些记录不能由 AI 代填。默认状态是 NO-GO，直到有真实记录。
- 不把"测试通过 / 命令退出码 0"写成"课程可发布"。

## 5. 内容原则

1. **证据优先。** 关键主张必须有可定位的来源；模型自信程度不算证据。
2. **区分事实、推导、示例与未知。** 不确定的内容必须标注，不能用猜测补事实缺口。
3. **冲突不自动裁决。** 来源冲突要同时列出两种口径，选择安全的呈现方式并披露。
4. **不夸大结论。** 保留论文的适用条件与限定词（例如 `big`、dev/test 集、BLEU 口径）。
5. **课程服务于讲解。** 每个场景一个主要认知任务；动画必须解释结构或过程，不做装饰。

## 6. 非目标（当前阶段）

- 不要求直接生成最终 MP4；不做自动配音、自动剪辑、云端渲染。
- 不引入 LangGraph、Web Workbench 或自动质量路由（见 ADR 0007）。
- 不承诺自动判断科学正确性；`scientific_review` 永远报告 `NOT_RUN`，直到有真实专家记录。
- 不做像素级视觉 diff 的自动裁决；视觉基线只提示漂移，确认仍是人的动作。

## 7. 成功标准

以真实产物和可复跑命令为准，不以文档声明为准：

- 给定真实输入，能生成结构完整、场景齐全的课程包；
- 课件能离线打开，逐场景播放、复位、深链定位；
- 讲稿与场景一一对应，关键主张能回到来源；
- 自动检查发现问题时能定位到场景/元素，并能修复后回归；
- 同一输入重复构建得到相同内容（构建可复现）；
- 不能确认的内容在报告中显式为 `NOT_RUN` / `pending` / 披露项。

当前基准课程的真实状态、实测命令与剩余缺口见 [`QUALITY.md`](QUALITY.md) §7。
