## 3. 验收中发现并修复的问题

- 真实 Graphviz SVG 在根元素前包含两行 `DOCTYPE` 与
  `<!-- Generated by graphviz ... -->` 注释；原 `_strip_prolog` 只处理 XML
  声明与 DOCTYPE，导致“Graphviz 未返回 SVG”。
- 现 `_strip_prolog` 跳过 XML 声明、DOCTYPE 与前置注释；
  新增回归测试 `test_strip_prolog_skips_doctype_and_generated_comment`。
- 只有真实 `dot` 才能暴露该问题；stub 测试无法覆盖。


## 5. 版本与许可证

- CI 使用 Ubuntu 运行器默认包 **2.43.0**（`apt-get install graphviz`）。
- Windows 目标固定版本 **16.1.0**（winget），两者均满足 >= 2.40 的代码要求。
- Graphviz 许可证为 EPL-1.0（`LICENSE-THIRD-PARTY.md` 已记录；winget
  元数据标为 CPL-1.0，发布前以安装包内许可证文件为准）。
- 版本、可执行文件路径与来源均写入构建证据，不依赖“本机能跑”。
