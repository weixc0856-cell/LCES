## 二、发现

### F-01（major，P6 已补证据）口播曾包含台账未覆盖的超参数

- **定位**：`internal/speaker_script.json#slide-007:narration`；涉及 Adam `beta1=0.9`、
  `beta2=0.98`、`eps=1e-9`、`warmup 4000`、EN-FR `P_drop=0.1`。
- **证据**：这些值确实出现在本地来源 §5.3 Optimizer 与 §6.1（`b0050`），但
  `internal/evidence_ledger.csv` 没有对应证据行；`claims.json` 也没有对应 claim。
- **影响**：修订前，口播把“来源里有”说成“已进入证据链”，学习者和其他资产无法追溯；
  Gate 1 也不会检查非 BLEU 数值，因此不会发现。
- **已执行修订**：新增 claim-024（优化器与 warmup）、claim-025（EN-FR dropout）与
  evidence-035/036/037（原文切片）；`evidence_quotes_in_source` 保持 pass。
- **剩余动作**：由人工核验这三条证据与两个 claim；口播内容未改。
- **复验**：`lces validate`、`lces audit-course` 与 Gate B 均已重跑。

### F-02（minor）幻灯片与口播的架构细节不一致

- **定位**：`slide-002` 正文未写 `d_model=512`、`d_ff=2048`；口播写了。
- **证据**：claim-008 / evidence-012 支持这些维度；不是事实错误，而是资产不一致。
- **影响**：只看幻灯片的读者缺少维度；只听口播的读者得到幻灯片没有的细节。
- **建议**：把 512/2048 补进 `slide-002` 或阅读版第二节，或在口播中删去。
- **复验**：重跑 Gate B 的多资产检查（目前只校验章节 ID，需人工比对内容）。

### F-03（minor）位置编码“不参与梯度更新”未在证据中点明

- **定位**：`internal/speaker_script.json#slide-005:narration`。
- **证据**：正弦位置编码是固定函数，不参与训练；但当前 claim-009/evidence-013 只覆盖
  正弦/余弦与波长，没有直接引文说明“无梯度”。
- **影响**：这是一条正确的常识，但不在证据链内，属于“口播超出已核验范围”。
- **建议**：改为“正弦编码是固定函数（不是可学习参数）”，并在证据备注中说明；或删去。
- **复验**：对照 §3.5 与 claim-009 的备注。

### F-04（minor）课程未写死 arXiv 版本

- **定位**：`slide-007` warning、阅读版、口播中的“本地 arXiv 版本”。
- **证据**：本地来源是 `arXiv:1706.03762v7`（source_registry.origin）。
- **影响**：不同 arXiv 版本的 Table 2 可能不同；不写版本会让冲突披露显得模糊。
- **建议**：统一写成“arXiv:1706.03762v7 的 Table 2/摘要”。
- **复验**：全文搜索“arXiv”并核对。

### F-05（advisory）部分检查答案过于简短

- **定位**：10 个 `CheckBlock`，例如 Q3 的答案只有“之前。”。
- **证据**：每个检查都有 `rationale`，但答案本身不足以独立自测。
- **影响**：学习者可能只记住一个词，无法复述理由。
- **建议**：答案页使用完整句子；`answer-key.md` 已给出评分依据，可在正式试测前统一。
- **复验**：人工试读答案页。

### F-06（major，属于验收而非内容）20 分钟是 TTS 实测，不是学习者时长

- **定位**：`timing_evidence.json`（`method=tts_readthrough`，1197.62 秒）。
- **证据**：TTS 完整口播，不是人类讲者录音，也不是学习者完成课程的时间。
- **影响**：不能把 19.96 分钟当作“学习者完成时长”或产品验收的最终证据。
- **建议**：人工试听/录音确认；学习者试测单独记录课程开始/结束时间。
- **复验**：`lces accept-course --timing-confirmed` 必须由真人执行。

### F-07（advisory）视觉基线未更新

- **定位**：10 张截图与旧基线不同（Gate 3 `browser_visual_regression=warn`）。
- **影响**：无法判断差异是内容变更还是布局回归。
- **建议**：按 P6-E 的视觉审核表逐项确认后更新基线。
- **复验**：人工审核表 + 重新截图。
