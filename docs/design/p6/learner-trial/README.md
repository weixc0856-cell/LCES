# 学习者试测包

状态：**准备完成，尚未执行**。本目录没有任何参与者数据。

## 执行协议

1. 招募具备 Python 与基础深度学习背景的学习者；记录知情同意。
2. 学习者独立完成课程（幻灯片 + 阅读版），记录开始/结束时间。
3. 完成后立即发放 `questions.md`，独立作答，不提供答案。
4. 用 `answer-key.md` 评分，把逐题得分、错误类型和起止时间写入
   `session-log-template.csv`。
5. 收集 `feedback.md` 的开放式反馈。
6. 用 `results-template.json` 汇总；只填写真实数据，空缺保持 `null`。

## 数据规则

- 不收集姓名、邮箱等可识别信息；`participant_id` 使用匿名编号。
- 不把 TTS 时长当作学习者完成时长；以每人实际记录为准。
- 不把模拟或推断数据写入结果；没有参与者就写 `not_executed`。
- 结果只用于课程产品验收，不替代证据签署或发布审批。
